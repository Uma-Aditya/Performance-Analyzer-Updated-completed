Introduction

AI-based academic system to monitor and improve student performance.

Centralized platform for marks, tests, and placement activities.

Reduces manual paper work and improves record accuracy.

Problem Statement

Manual maintenance of student records is difficult.
Separate files make data management confusing.
Manual question paper preparation is slow.

Existing System

Paper-based or manual spreadsheet systems.
Disconnected department record-keeping.
No automated analysis or performance insights.

Drawbacks

Extremely time-consuming manual updates.
High risk of human errors in calculations.
Lack of real-time performance tracking.

Proposed System

Automated Excel marks upload and processing.
AI-driven automated test generation engine.
Centralized dashboard for all user roles.

Project Objectives

Create a single platform for all academic data.
Support automated performance analysis.
Provide quick placement and job notifications.

Project Modules

Authentication & User Management.
Marks Management & Bulk Uploads.
AI Test Engine & Online Portal.
Analytics & Visual Reports.

Technologies

Frontend: React.js & Tailwind CSS.
Backend: Python & FastAPI.
Database: SQLite (Lightweight).
AI Engine: Google Gemini AI.

System Architecture

Robust 3-Layer Design:

Presentation Layer: React.js UI.
Logic Layer: FastAPI Backend.
Data Layer: SQLite Storage.

Expected Output

Accurate and automated student reports.
Interactive performance trend charts.
Faster test preparation via AI engine.

Future Scope

Add JWT-based secure auth sessions.
Integrate predictive AI modeling.
Build a native mobile tracking app.

Conclusion

A modern solution for institutional management.

Streamlining academics and placements via automation.
