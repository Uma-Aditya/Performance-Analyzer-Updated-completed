API Endpoints

Login API: Used for user authentication; checks the username, password, and user role.
Student API: Used for managing student records; Admin can add, update, and view student details.
Marks Upload API: Used for uploading Excel files; processes marks data and stores it in the database.
Test Generation API: Used for AI-based questions; faculty can generate questions automatically.
Job API: Used for placement opportunities; placement officers can add and manage jobs.
