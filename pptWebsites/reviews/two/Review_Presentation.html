Abstract

Performance Analyzer is a web-based system developed to simplify student performance tracking and analysis.

The system allows faculty to upload marks, conduct online tests, and generate performance reports.

The goal is to reduce manual work and provide a centralized platform for academic monitoring.

Objectives

Develop a centralized management platform.
Reduce manual work in marks calculation.
Provide role-based access for all users.
Support AI-based online test generation.
Generate visual performance analytics.
Manage placement and job opportunities.

Existing System

Records maintained manually or in spreadsheets.
Disconnected tracking for marks and tests.
Time-consuming manual paper preparation.
High chance of human errors in calculations.
Difficulty in tracking performance trends.

Drawbacks

Process is time-consuming and difficult to maintain.
Manual calculations lead to data entry mistakes.
Student performance is difficult to track effectively.
Lack of automation and smart AI-based insights.

Proposed System

Centralized platform for marks and analytics.
Excel-based bulk marks upload functionality.
AI generates MCQs automatically for faculty.
Integrated job board for student notifications.
Personalized role-based user dashboards.

Technologies

Frontend: React.js & TypeScript.
Backend: Python & FastAPI.
Database: SQLite & SQLAlchemy.
AI Engine: Google Gemini AI API.
Data: Pandas & OpenPyXL.

Project Modules

Authentication & Role Management.
Student & Faculty Record Management.
Excel Marks Ingestion Module.
Automated AI Online Test Engine.
Analytics & Visualization Module.
Placement & Job Notification Board.

Architecture

Presentation: React Frontend interfaces.
Application: FastAPI Backend logic.
Data Layer: SQLite persistence storage.
Flow: User → Frontend → Backend → DB.

System Flow

User login based on assigned role.
Faculty uploads bulk marks via Excel.
AI generates MCQs for assessments.
Students take tests and view scores.
TPO posts job updates for students.

Database Tables

Students: Roll numbers, names, sections.
Teachers: Faculty profiles and subjects.
Performance: Academic marks and stats.
Tests: Question banks and assessments.
Jobs: Placement opportunities board.

Test Cases

Verified Admin and Role-based Login.
Validated Excel data storage accuracy.
Confirmed AI question generation flow.
Tested assessment scoring precision.
Verified job board visibility alerts.

Future Scope

Add JWT-based secure session sessions.
Integrate predictive AI performance models.
Include Attendance and Assignment modules.
Build a native mobile tracking application.

Conclusion

A complete solution for student tracking through automation and AI.

The system reduces workload and provides actionable performance insights.

Successfully moving towards a fully functional management platform.
