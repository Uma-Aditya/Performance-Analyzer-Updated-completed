FRONTEND INSTALLATION GUIDE

Prerequisites:
- Node.js 18.0 or higher
- npm

Steps:
1. Navigate to 'Performance-Analyzer' directory.
2. Install packages: npm install
3. Setup .env (optional): VITE_API_BASE_URL=http://localhost:8000
4. Run dev server: npm run dev
5. Access: http://localhost:8080

Production:
Run 'npm run build' to generate the 'dist' folder for deployment.
